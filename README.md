# Spooky Pet

Spooky Pet is a macOS desktop companion that wanders around your screen and occasionally heckles you. It reacts to clicks, app switches, and a timer. Jokes can be generated by an OpenAI-compatible chat API, with built-in lines as a fallback.

This fun project was created for the AI Builders Glasgow Hackoween on 29 October 2026.

## Requirements

- macOS, with Xcode Command Line Tools installed (`xcode-select --install`). The app uses macOS-specific APIs.
- [Node.js and npm](https://nodejs.org/) and the [Rust toolchain](https://rustup.rs/). See the [Tauri 2 prerequisites](https://v2.tauri.app/start/prerequisites/) for platform setup.
- Optional: [Task](https://taskfile.dev/) for the shortcuts in `Taskfile.yml`.
- Optional: an [OpenRouter](https://openrouter.ai/) API key or another compatible chat-completions endpoint for generated jokes. The app works without a key using local fallback lines.

## Run from source

From the repository root:

```sh
npm ci
npm run tauri -- dev
```

This starts Vite and the Tauri desktop app. The first Rust build may take a while. Alternatively, run `task setup` followed by `task dev` if Task is installed.

## Build and install

```sh
npm ci
npm run tauri -- build --bundles app --no-sign
```

The unsigned app is built at `src-tauri/target/release/bundle/macos/Spooky Pet.app`. Open it directly, or copy it to `/Applications` to install it. macOS may require you to approve an unsigned app in Privacy & Security before opening it. `task build` performs the same build, and `task open` launches the resulting bundle.

## Using the pet

- Click the pet to request a joke; drag it to move it. Click a speech bubble to dismiss it.
- Use the Spooky Pet menu-bar icon to hide or show the pet, mute or unmute it, or quit. The app has no Dock icon.
- The pet also reacts to app switches and a randomized timer. A cooldown limits interruptions.

## Configuration

On first launch, the app creates `~/Library/Application Support/fun.spooky-pet/settings.json`. Edit this file with a text editor; `task settings` opens it if it exists. Settings are re-read during operation, including before jokes and sounds. Keep the JSON valid. Omitted fields use defaults.

```json
{
  "api_key": "",
  "model": "google/gemma-4-31b-it",
  "base_url": "https://openrouter.ai/api/v1",
  "timer_min_seconds": 300,
  "timer_max_seconds": 600,
  "cooldown_seconds": 60,
  "sound": true,
  "font_size": 18,
  "popup_opacity": 0.9,
  "chunk_delay_seconds": 8,
  "profile": {
    "name": "",
    "role": "",
    "interests": "",
    "roast_level": "gentle",
    "do_not_joke": [],
    "pet_name": ""
  }
}
```

Set `api_key` to enable generated jokes, and choose a model available through your provider. The app sends requests to `<base_url>/chat/completions` with a bearer token; an empty key, failed request, or empty response uses a built-in line. API usage may incur provider charges. The key is stored as plaintext in the settings file, so keep it private.

Timer and cooldown values are in seconds. `sound` controls sound effects; the menu-bar mute control also pauses the pet. `font_size` is clamped to 11–32, `popup_opacity` to 0.2–1.0, and `chunk_delay_seconds` to 1–60. The profile personalizes jokes: `roast_level` accepts `gentle`, `mean`, or `cursed`, and `do_not_joke` is a list of topics to avoid.

When an API key is set, requests include the profile, frontmost app name and bundle ID, trigger, and time of day. Debug builds also log the request body to the terminal. Review your provider's data policies before adding personal information to the profile.

## Development and checks

The frontend lives in `src/overlay`; the Rust/Tauri host is in `src-tauri/src`. Vite uses port 1420 for development.

```sh
npm test                              # JavaScript tests
cargo test --manifest-path src-tauri/Cargo.toml
cargo fmt --manifest-path src-tauri/Cargo.toml -- --check
cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets -- -D warnings
```

Install the Rust formatting and lint components with `rustup component add rustfmt clippy` if needed. `task verify` runs the Rust format check, Clippy, and Rust tests; run `npm test` separately. `npm run build` builds only the frontend, while the Tauri build command above produces the desktop app.

## Task commands

With [Task](https://taskfile.dev/) installed, run these commands from the repository root. `task` or `task --list` lists the available tasks.

| Command | Purpose |
| --- | --- |
| `task setup` | Install npm dependencies and the Rust formatting and Clippy components. |
| `task dev` (`task run`) | Start the desktop app in development mode with hot reload. |
| `task build` | Build an unsigned release `.app` bundle. |
| `task build:debug` | Build an unsigned debug `.app` bundle. |
| `task open` | Open the release app after building it (macOS). |
| `task check` | Check the Rust host for compilation errors. |
| `task fmt` | Format Rust source files. |
| `task fmt:check` | Check Rust formatting without changing files. |
| `task lint` (`task clippy`) | Run Clippy on all Rust targets, treating warnings as errors. |
| `task test` | Run Rust tests. Use `npm test` separately for JavaScript tests. |
| `task verify` (`task ci`) | Run the Rust formatting check, Clippy, and Rust tests. |
| `task clean` | Remove Cargo build artifacts and the Vite `dist` directory. |
| `task info` | Show Tauri, Rust, and Node environment information. |
| `task settings` (`task settings:open`) | Open the settings file in the default editor, or print its path if it does not exist yet (macOS). |
| `task settings:path` | Print the settings file path (macOS). |
| `task settings:reveal` | Open the settings directory in Finder, creating it if necessary (macOS). |
| `task stop` (`task kill`) | Stop leftover Spooky Pet processes (macOS). |
